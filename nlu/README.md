# Natural language understanding (`nlu/`)

This folder contains code, data, and models for the Natural Language Understanding (NLU) module.
To run code from the app module, you will need the models' files to be adequately placed in this folder.

> If you don't have these files, get in touch with the team for further instructions.

How to test the entire `nlu` module? (Note: this may require the models)
```
python tests/test_nlu.py
```
